# Schibsted Grotesk

The Latin variable font is vendored from
`@fontsource-variable/schibsted-grotesk@5.3.0`, sourced from Google Fonts and
licensed under the SIL Open Font License in `OFL.txt`.

The npm package was fetched with normal TLS and npm integrity verification.
Its archive integrity is
`sha512-ndS6H/KICWANchlHF3q4UdZD+xrZ3Ji0rUobIuXlgvDUzDfqZDsVuXPXZb636nJZMHE9zZ9Fmwgqazm8hMB50Q==`.

`next/font/local` serves the font from the same origin. This keeps builds
independent of Google Fonts network access and avoids font requests to Google
from visitors' browsers. The variable weight range is 400–900.
